days with any DP

DP time is counted between DP ON and DP OFF entries: the DP light, or any entry containing “DP ON” / “on DP” and “DP OFF” / “off DP” / “out of DP”. With hours of the day chosen, only DP time inside those hours is counted, each day. However many hours the vessel is on DP in a day, it counts as one DP day. This is the vessel's time on DP – in a personal DP logbook only your own time on DP watch counts.

Print / save as PDF

To save a PDF, choose “Save as PDF” as the printer (on iPad / iPhone: Share in the print preview).

Import backup

Merge adds the entries from the file that are not here yet and keeps everything already on this device. Replace deletes what is on this device and loads the file instead.

Settings

These appear in the drop-down when you fill in an event. End a line with … to leave it open for typing more, e.g. “Heading changed to …”. Events you typed by hand before are also offered automatically.

Data

Every change is saved automatically as you type, in this browser on this device only. To use the logbook on another device, save a backup file here and import it there – you can merge it with what is already on that device or replace it. Save a backup file regularly.
